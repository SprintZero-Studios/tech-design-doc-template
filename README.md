# Technical design document template

A technical design document template in Markdown: overview, data flow,
components, data models, schema, a tech stack with a reason for every layer,
ordered engineering tasks and open questions.

- `TECH-DESIGN.md`: the template. Guidance sits in HTML comments, which GitHub hides.
- `examples/creature-clash-tech-design.md`: a filled example, the engineering
  brief from a real Murmur run (Creature Clash: Duel Loop Prototype), published with the owner's permission.

Use it: click "Use this template", or copy TECH-DESIGN.md into your repo.
